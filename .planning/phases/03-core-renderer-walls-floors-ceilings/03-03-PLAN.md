  <name>Task 1: Row-based floor/ceiling casting behind CONFIG.FLOOR_CAST (REND-03)</name>
  <files>Doom/Claude Opus 4.8/GSD/js/raycaster.js</files>
  <action>
Replace the tracer's flat two-tone Pass A with the row-based cast, gated `if (CONFIG.FLOOR_CAST) { ... }` (RESEARCH Pattern 3, CONTEXT decision 5 — REND-03). Compute the leftmost/rightmost ray directions once: rayDirX0 = dirX - planeX, rayDirY0 = dirY - planeY (cameraX = -1); rayDirX1 = dirX + planeX, rayDirY1 = dirY + planeY (cameraX = +1). posZ = CONFIG.CAMERA_Z * H. floorTex = Textures.map.floor, ceilTex = Textures.map.ceiling; fBuf = floorTex.buf32, cBuf = ceilTex.buf32. TEX = CONFIG.TEX_SIZE, MASK = TEX - 1.

For y from horizon + 1 to H - 1 (starting at horizon + 1 makes (y - horizon) >= 1 — the y-horizon==0 divide is avoided structurally): p = y - horizon; rowDistance = posZ / p (constant for the whole row; also the shade distance). Per-row world step and leftmost world position: floorStepX = rowDistance * (rayDirX1 - rayDirX0) / W; floorStepY = rowDistance * (rayDirY1 - rayDirY0) / W; floorX = px + rowDistance * rayDirX0; floorY = py + rowDistance * rayDirY0. Hoist rowShade = shadeFactor(rowDistance, false) ONCE per row. floorRowBase = y * W; ceilRowBase = (H - 1 - y) * W (mirror across the horizon).

Inner loop x in [0, W): tx = ((floorX * TEX) | 0) & MASK; ty = ((floorY * TEX) | 0) & MASK; floorX += floorStepX; floorY += floorStepY; ti = (ty << 6) + tx; Framebuffer.buf32[floorRowBase + x] = applyShade(fBuf[ti], rowShade); Framebuffer.buf32[ceilRowBase + x] = applyShade(cBuf[ti], rowShade). No divides/trig/allocation in the inner loop — only masks, adds, packed reads, shaded writes.

Fill the exact horizon row (y === horizon) as well (e.g. shade it at the nearest row's distance) so no pixel across the frame is left unwritten. This Pass A runs BEFORE the wall Pass B, which then overwrites the wall spans; floors/ceilings never touch zBuffer.
