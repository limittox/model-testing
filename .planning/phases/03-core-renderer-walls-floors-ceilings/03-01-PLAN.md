Raycaster (js/raycaster.js, NEW classic script — same shape as topdown.js): a global var Raycaster = { render: function () { ... } } that writes Framebuffer.buf32 and Framebuffer.zBuffer and does NOT present. Read W = Framebuffer.width, H = Framebuffer.height, horizon = H >> 1 at the TOP of every render() call (never cache across frames). Cache the pose into locals (px, py, dirX, dirY, planeX, planeY) once per frame.

  PASS A (whole-frame fill, establishes the 3-pass skeleton): fill rows [0, horizon) with CONFIG.CEIL_COLOR and rows [horizon, H) with CONFIG.FLOOR_COLOR so every pixel is written and the horizon reads. This flat two-tone fill is the skeleton Pass A that 03-03 expands into the row-based cast + shaded flat-color fallback — a functionality expansion, not an architecture change (Pass A always fills the frame first; Pass B always overwrites wall spans).

  PASS B (per-column DDA wall cast — CONTEXT decision 2 / RESEARCH Pattern 1, REND-01 + REND-06): for each column x in [0, W): cameraX = 2*x/W - 1; rayDirX = dirX + planeX*cameraX; rayDirY = dirY + planeY*cameraX. mapX = Math.floor(px), mapY = Math.floor(py). Guard axis-aligned rays with a large FINITE sentinel (BIG = 1e30, the LOS_BIG idiom): deltaDistX = (rayDirX === 0) ? BIG : Math.abs(1/rayDirX), likewise deltaDistY. Seed stepX/stepY and sideDistX/sideDistY from the fractional position exactly as Level.lineOfSight does. DDA: a while-loop bounded by a countdown guard initialised to Level.WIDTH + Level.HEIGHT + 2, stepping whichever side has the smaller sideDist (setting side = 0 for an x-step, 1 for a y-step) until Level.isSolid(mapX, mapY); break on the guard so a malformed/borderless map cannot spin. perpWall = (side === 0) ? (sideDistX - deltaDistX) : (sideDistY - deltaDistY) — the PERPENDICULAR distance; NEVER a Euclidean hypot to the hit point. Floor it with if (!(perpWall > EPS)) perpWall = EPS (EPS = 1e-4) so a hit at ~0 distance, a negative, or a NaN cannot poison the buffer. Write Framebuffer.zBuffer[x] = perpWall for EVERY column, unconditionally (REND-06). lineHeight = Math.floor(H / perpWall); drawStart = -(lineHeight >> 1) + horizon; drawEnd = (lineHeight >> 1) + horizon; clampedStart = drawStart < 0 ? 0 : drawStart; clampedEnd = drawEnd > H ? H : drawEnd. Fill [clampedStart, clampedEnd) of column x with a solid base color for the hit wall id: keep a tiny packed-color table on the Raycaster keyed 1..5 (index-aligned to Level.WALL_TEXTURES; a fail-safe stone color when Level.cellAt returns an unexpected id), and apply the one-op y-side depth cue (color >> 1) & 0x7F7F7F when side === 1 so perpendicular walls read as lit differently. This solid base color is what 03-02 replaces with the sampled, fog-shaded texel.

  No Framebuffer.present() anywhere in Raycaster. No allocation in either pass — only loop scalars; reuse the preallocated Framebuffer/zBuffer buffers; never read pixels back from the 2D context.

index.html: add exactly one classic tag, <script src="js/raycaster.js"></script>, AFTER js/topdown.js and BEFORE js/game.js (raycaster reads CONFIG/Framebuffer/Level/Player/Textures and is read by nothing before game.js).
