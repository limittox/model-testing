  <name>Task 1: Distance shading + fog + constant y-side darken (REND-04)</name>
  <files>Doom/Claude Opus 4.8/GSD/js/raycaster.js</files>
  <behavior>
    - shadeFactor(0, false) returns 256 (full brightness at the camera); shadeFactor(CONFIG.FOG_FAR, false) clamps to the floor, (CONFIG.MIN_SHADE * 256) | 0, and never below it.
    - shadeFactor(d, true) equals shadeFactor's pre-side value times CONFIG.SIDE_SHADE (a y-side column is darker than an x-side column at the same distance).
    - applyShade(packed, 256) preserves the packed rgb; applyShade always forces the alpha byte to 0xFF (no translucent pixels); channels are the little-endian layout of packRGBA (no red/blue swap).
    - A near wall column is brighter on average than a far wall column; no shaded channel for the nearest geometry drops below (CONFIG.MIN_SHADE * 255) | 0.
  </behavior>
  <action>
Add two module-level helpers to js/raycaster.js (RESEARCH Pattern 5, CONTEXT decision 4 — REND-04):

shadeFactor(dist, isYSide): s = 1 - dist / CONFIG.FOG_FAR (linear falloff: 1 at the camera, 0 at FOG_FAR). Clamp: if (s < CONFIG.MIN_SHADE) s = CONFIG.MIN_SHADE; if (s > 1) s = 1. Then if (isYSide) s *= CONFIG.SIDE_SHADE. Return (s * 256) | 0 — an INTEGER fixed-point shade in [0, 256], so the inner loop is (channel * shade) >> 8 with no float multiply.

applyShade(packed, shade): unpack r = packed & 0xFF, g = (packed >> 8) & 0xFF, b = (packed >> 16) & 0xFF; scale each by (channel * shade) >> 8; repack as (0xFF000000 | (b << 16) | (g << 8) | r) >>> 0 — matching packRGBA's little-endian layout exactly and forcing an opaque alpha byte.

In the Pass B wall loop, compute colShade = shadeFactor(perpWall, side === 1) ONCE per column, immediately after perpWall is finalised — perpWall is constant for the whole column, so the shade is too. Replace the tracer's one-op (color >> 1) & 0x7F7F7F y-side darken: write the wall column's solid base color through applyShade(base, colShade) instead. The full fog curve + MIN_SHADE floor + constant SIDE_SHADE now supersede the crude darken. Keep it branch-light and allocation-free (helpers return numbers, not objects; no closures created in the loop).
  </action>

  <name>Task 2: Wall texture-column sampling with side flips + seam masking (REND-02)</name>
  <files>Doom/Claude Opus 4.8/GSD/js/raycaster.js</files>
  <behavior>
    - For a column hitting the asymmetric exit wall, dropping either side-based texX flip changes the sampled texX (the arrow mirrors) — a hand-computed texX/texY in the harness matches the rendered pixel only with both flips present.
    - texX and texY always land in [0, 63] (no index escapes the 64x64 texture, including the wallX*64 == 64.0 boundary case).
    - A tall near wall (small perpWall, drawStart negative) samples the correct visible slice because texPos is referenced to the unclamped span, not the clamped top.

  <action>
Replace the solid base-color wall write with per-column texture sampling (RESEARCH Pattern 2, CONTEXT decision 3 — REND-02). Resolve the texture ONCE per column, before the row loop: id = Level.cellAt(mapX, mapY); tex = Level.textureFor(id); if (!tex) tex = Textures.map.stone (fail-safe; Level.validateTextures() guarantees none missing). TEX = tex.width (64), MASK = TEX - 1.

Horizontal: wallX = (side === 0) ? (py + perpWall * rayDirY) : (px + perpWall * rayDirX); wallX -= Math.floor(wallX). texX = Math.floor(wallX * TEX). Apply BOTH side-based flips for consistent handedness (no mirror at corners): if (side === 0 && rayDirX > 0) texX = TEX - texX - 1; if (side === 1 && rayDirY < 0) texX = TEX - texX - 1. Then texX &= MASK (belt-and-braces: wallX*64 can reach 64.0 at a grid boundary).

Vertical (fixed-point, referenced to the UNCLAMPED line): step = TEX / lineHeight; texPos = (drawStart - horizon + (lineHeight >> 1)) * step. If the top was clipped, advance over the hidden rows first: if (clampedStart > drawStart) texPos += (clampedStart - drawStart) * step. Do NOT reference texPos to clampedStart — that re-anchors the texture to the screen edge and the wall swims as you approach.

Row loop for y in [clampedStart, clampedEnd): texY = (texPos | 0) & MASK; texPos += step; texel = tex.buf32[(texY << 6) + texX]  (texY*64 + texX); Framebuffer.buf32[y * W + x] = applyShade(texel, colShade)  (the same colShade computed once per column in Task 1). This replaces the solid base-color write entirely — walls are now textured and fog-shaded through the identical shade path; the tracer's crude one-op y-side darken is superseded by the shadeFactor path.
