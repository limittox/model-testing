DATA MODEL (CONTEXT decision 1, ENT-01). `Entities.list` is a preallocated array of plain objects `{x, y, sprite, scale, onFloor}`, populated by `Entities.build()` from `Level.spawns`. Map spawn.type -> sprite key + scale: `enemy` -> sprite 'enemy', scale 1.0, onFloor true; `health`/`armor`/`ammo`/`shotgun` -> sprite 'pickup', scale 0.5, onFloor true. Skip `exit` and `player` (no exit sprite exists this phase — leave exit markers to Phase 6; note this in a comment). Copy spawn.x/spawn.y (cell-centre world coords) into each entity. Do NOT add behaviour fields (health/state/etc.) — Phase 5 owns them. build() is idempotent (rebuilds list fresh); call it AFTER Level.build() and Sprites.build().

SORT SCRATCH (allocation-free, CONTEXT decision 2 + specifics). Preallocate two scratch buffers sized to the list length: `Entities._order` (Int32Array of entity indices) and `Entities._dist2` (Float64Array of squared distances). If the list grows beyond current scratch capacity, reallocate once (not per frame). No allocation in render().

SPRITE PASS `Entities.render()` (CONTEXT decisions 2, 3, 4). Runs each frame AFTER the wall pass has filled zBuffer and BEFORE present. Read `Framebuffer.width` (W), `Framebuffer.height` (H), `Framebuffer.buf32` (buf), `Framebuffer.zBuffer` (zbuf) LIVE. Snapshot the Player pose (px,py,dirX,dirY,planeX,planeY) and `Sprites.ALPHA_KEY` into locals once. Steps:
  1. Fill `_dist2[i] = relX*relX + relY*relY` (relX=e.x-px, relY=e.y-py) and `_order[i]=i` for every entity; sort `_order` by `_dist2` DESCENDING (far first) using an in-place INSERTION sort over the preallocated index array (allocation-free; Array.sort with a closure comparator is forbidden here).
  2. Compute `invDet = 1/(planeX*dirY - dirX*planeY)` ONCE.
  3. For each entity in far->near order: relX/relY; `transformX = invDet*(dirY*relX - dirX*relY)`; `transformY = invDet*(-planeY*relX + planeX*relY)`. NEAR clip: if `transformY <= NEAR` (define NEAR = 0.05) skip this entity (behind camera / at plane).
  4. `spriteScreenX = Math.floor((W/2)*(1 + transformX/transformY))`. `spriteDim = Math.abs(Math.floor(H/transformY)) * e.scale` — use screen HEIGHT H for BOTH the width and height scale so billboards stay square on any aspect (CONTEXT decision 3; using W would distort on widescreen). `vMove = e.onFloor ? H*(1 - e.scale)/2 : 0`; `vMoveScreen = Math.floor(vMove/transformY)`.
  5. Unclamped span origins (keep these for texel mapping even after clamping — same discipline as the wall pass texPos): `originX = -spriteDim/2 + spriteScreenX`; `originY = -spriteDim/2 + (H/2) + vMoveScreen`. Clamped loop bounds: `drawStartX = max(0, originX)`, `drawEndX = min(W, originX + spriteDim)`, `drawStartY = max(0, originY)`, `drawEndY = min(H, originY + spriteDim)`.
  6. Resolve the sprite asset: `tex = Sprites.map[e.sprite]`; `TEXW = tex.width`, `TEXH = tex.height`, `tbuf = tex.buf32`.
  7. Per stripe `stripe` in `[drawStartX, drawEndX)`: OCCLUSION (CONTEXT decision 4, ENT-02) — process the column ONLY if `transformY > 0 && stripe >= 0 && stripe < W && transformY < zbuf[stripe]`. Compute `texX = Math.floor((stripe - originX) * TEXW / spriteDim)`, clamp to `[0, TEXW-1]`.
  8. Per row `y` in `[drawStartY, drawEndY)`: `texY = Math.floor((y - originY) * TEXH / spriteDim)`, clamp to `[0, TEXH-1]`; `packed = tbuf[texY*TEXW + texX]`. TRANSPARENCY (CONTEXT decision 5, ENT-03) — if `((packed >>> 24) & 0xff) < ALPHA_KEY` skip this texel (leave the background pixel intact). Otherwise write `buf[y*W + stripe] = packed` (UNSHADED in this tracer — the fog-shade path is 04-02's functionality fill; this is a deferred functionality gap, not an architectural one). The sprite pass NEVER writes zbuf.

SEAM (CONTEXT decision 2 + decision 8). In `js/raycaster.js`, add a `spritePass: null` field to the `Raycaster` object and, as the LAST statement of `Raycaster.render()` (after Pass B's `for x` loop closes), invoke `if (Raycaster.spritePass) Raycaster.spritePass();`. This keeps `Game.view === Raycaster` and the single present in `Game.render` intact while running sprites after the wall pass. Add a short comment documenting the seam.

WIRING. In `index.html`, add `<script src="js/entities.js"></script>` immediately AFTER `js/raycaster.js` and BEFORE `js/game.js`, and extend the numbered load-order contract comment to 13 scripts describing entities.js (defines Entities: the spawn-derived billboard list + the sprite pass invoked via Raycaster.spritePass; reads Framebuffer/Player/Level/Sprites/Raycaster; read by nothing before game.js). In `js/main.js`, after `Level.build()` and `Sprites.build()`, call `Entities.build()`, and after `Game.view = Raycaster` add `Raycaster.spritePass = Entities.render;` with a comment.
