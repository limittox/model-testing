  <action>
Wire ONE path through every layer of the shell, end to end, production-quality.

config.js — attach a single global namespace object `CONFIG` with the resolution and color tuning constants: `INTERNAL_W` (fixed low width, default 480), `MIN_H`/`MAX_H` (height clamp bounds, default 240/300), `FOV_PLANE` (camera-plane length, 0.66), `TEX_SIZE` (64, power-of-two), `SEED` (an integer for later procedural determinism), and `CLEAR_COLOR` (a distinct dark non-black slate). Also expose two global helper functions: `packRGBA(r,g,b,a)` returning `((a<<24)|(b<<16)|(g<<8)|r) >>> 0` with `a` defaulting to 255, and `mulberry32(seed)` returning a seeded PRNG closure (used by Plan 02). Define `CLEAR_COLOR` via `packRGBA` so the packed-color contract is exercised here.

framebuffer.js — attach a global `Framebuffer` object holding the render surface: `init(gameCanvas, hudCanvas)` stores the #game 2D context and calls `resize()`; `resize()` computes the current internal height as `clamp(round(INTERNAL_W * window.innerHeight / window.innerWidth), MIN_H, MAX_H)`, sets `gameCanvas.width=INTERNAL_W`/`gameCanvas.height=height`, and (only when dimensions actually change) creates one ImageData at internal size, exposing `Framebuffer.img`, `Framebuffer.buf8` (the ImageData.data Uint8ClampedArray), `Framebuffer.buf32` (a Uint32Array view over `buf8.buffer` — the authoritative pixel buffer), and `Framebuffer.zBuffer` (a Float32Array sized to INTERNAL_W); `clear(packed)` does `buf32.fill(packed >>> 0)`; `present()` does a single `ctx.putImageData(img, 0, 0)`. Expose `Framebuffer.width`/`Framebuffer.height` as the authoritative resolution source of truth (height varies with the viewport). For the tracer, `resize()` may size the #hud canvas to `window.innerWidth`/`window.innerHeight` (fully hardened in Task 2).

index.html — a minimal document with `<meta charset>`, a `<canvas id="game">` and `<canvas id="hud">`, then classic `<script src>` tags in the fixed order `js/config.js` -> `js/framebuffer.js` -> `js/main.js`. Add an HTML comment block at the script list documenting the load-order contract (order encodes the dependency graph; later files extend earlier globals). Use only classic script tags — no bundler, no ES-module system, no runtime network loads; every asset is co-located and referenced by a relative path.

style.css — `html,body{margin:0;height:100%;background:#000;overflow:hidden}`; stack both canvases absolutely to fill the viewport (`position:absolute;inset:0;width:100vw;height:100vh;display:block`); on #game set `image-rendering: pixelated` with an `image-rendering: crisp-edges` fallback line; on #hud set `pointer-events:none`.

main.js — on window load, look up `#game` and `#hud`, call `Framebuffer.init(game, hud)`, then `Framebuffer.clear(CONFIG.CLEAR_COLOR)` and `Framebuffer.present()`. Register a `resize` handler that calls `Framebuffer.resize()` then re-clears and re-presents (Phase 1 has no animation loop, so the color must be repainted after any buffer reallocation).
