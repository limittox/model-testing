- HUD (from 06-01): HUD.render() clears and repaints the whole #hud canvas every frame, returns
  early when Framebuffer.hudCtx is missing, never calls putImageData or getImageData, dispatches
  on Game.state to one of the three screens, and draws nothing in the playing state. HUD.reset()
  is the rebuild hook. Sizes come from a preallocated metrics record recomputed in place.
- Framebuffer.hudCtx is the #hud 2D context; Framebuffer.hudCanvas is that canvas and its width
  and height are the DISPLAY dimensions. Framebuffer.resize() clears the backing store, which is
  why the repaint is unconditional every frame (D-01).
- Combat.health, Combat.armor, Combat.maxHealth, Combat.maxArmor, Combat.ammo.bullets,
  Combat.ammo.shells, Combat.weapon, Combat.hasShotgun, Combat.dead, Combat.lastDamageAt (the
  Game.time of the most recent damaging hit, -1 when never) and Combat.totalDamageTaken.
- Combat.PISTOL and Combat.SHOTGUN are the two weapon name strings; Combat.selectWeapon(name)
  returns whether the selection actually CHANGED, and refuses the shotgun until hasShotgun.
- Weapons.TABLE is keyed by weapon name and each entry names the Combat.ammo field it spends;
  Weapons.update(dt, intent) owns the selection and firing decisions; Weapons.fire() returns
  whether a shot left the barrel and sets Weapons.lastDryFire true on a refusal, false on a
  successful shot — that false-to-true edge is the only correct place to hang a one-shot
  out-of-ammo reaction, because a held trigger at zero ammo calls fire() every single frame.
- Game.state, Game.STATES, Game.kills, Game.totalKills, Game.time, Game.message(text),
  Game.activeMessage(), Game.messagesPosted.
- Level.WIDTH, Level.HEIGHT, Level.cells (row-major wall IDs, 0 meaning floor), Level.isSolid,
  Level.exit (derived in 06-01), Level.playerStart.
- Player.x, Player.y, Player.dirX, Player.dirY.
- Enemies.list entries carry x, y, alive and state (Enemies.CORPSE is the terminal one);
  Pickups.list entries carry x, y, active and itemType.
- tools/boot.cjs: h.canvas('hud').getContext('2d') returns a CACHED no-op recording surface —
  the same object Framebuffer.hudCtx holds — whose drawing methods a harness can wrap to record
  calls. document.createElement returns a canvas stub whose getContext('2d') is the same shape,
  so an offscreen prebuild works headlessly. h.raf.step(ms) drives one real frame.
