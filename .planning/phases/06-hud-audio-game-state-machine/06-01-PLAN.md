make the project's core value true end to end: open the page, see a title screen with the
controls, CLICK ONCE to start playing, fight through the level, reach the exit and get a
victory screen with your stats — or die and get a death screen — then click to play again.

start, win, lose or restart is a demo, not a game.

js/hud.js overlay module with the three screens, and tools/verify-state.cjs.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user gesture -> game state | A single untrusted click starts play, unlocks audio and requests pointer lock |
