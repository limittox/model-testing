<objective>
Give the game its voice. Replace the recording stub inside js/sound.js with a real Web Audio
engine — one gesture-scoped AudioContext, a master gain into a compressor into the destination,
and six distinct effects synthesized from oscillators, white noise, gain envelopes and biquad
filters — and wire the five gameplay call sites that are still silent.

Purpose: a shooter with no sound is not a shooter. Every hit, shot, death and pickup needs an
answer, and it must arrive without a single byte of audio being downloaded.

Output: CONFIG.SFX, the js/sound.js engine, five new call sites, and tools/verify-audio.cjs.

BOUNDARY: this plan does not touch the HUD, the state machine or the overlay. It keeps
Sound.play's existing signature, recorder body and return semantics exactly as they are, because
every Phase 5 assertion that counts hook calls depends on them.
</objective>

2. THE ENGINE (js/sound.js) — replace the internals, keep the surface.
   - Sound.unlock(): resolve the constructor from the global at CALL TIME (the standard name
     first, then the webkit-prefixed one) — never capture it at module load, because that is
     exactly what would make the never-before-the-gesture assertion untestable and would break the
     harness's ability to install a stub after boot. Construct at most one context, build the
     master chain once (a gain node into a compressor into the destination, configured from
     CONFIG), call resume only when the context reports itself suspended, and set an availability
     flag. Wrap the whole body in a try/catch that records the failure and leaves audio
     unavailable. Always increment unlockCalls and always return whether audio is now available.
     It must be safe to call any number of times.
   - Sound.play(name): the guard and the recorder run FIRST and byte-for-byte as they do today,
     including the exact return values. Only then, and only when a context exists and audio is
     available, resolve the recipe and synthesize. The whole synthesis block sits inside a
     try/catch so no audio failure can ever propagate into the frame. An unknown name records and
     returns exactly as today without synthesizing.
   - Sound.RECIPE_FOR maps an EVENT name to a recipe key, so the four pickup event names can share
     the pickup recipe while remaining four distinct events at the call sites. A table, not a
     chain of comparisons.
   - ONE generic synth(recipe) interprets a CONFIG.SFX entry: build the tone layer as an
     oscillator with its frequency swept from the start to the end value across the decay; build
     the noise layer from a white-noise buffer (generated once at unlock into a cached AudioBuffer
     and replayed through fresh buffer sources, so no per-shot buffer is filled); route the layers
     through an optional biquad whose cutoff sweeps, then a per-sound gain, then the master gain.
     Schedule the gain envelope against the context's own currentTime: set the floor epsilon, ramp
     up to the peak across the attack, ramp back down to the epsilon across the decay — never to
     exactly zero. Start each source at the scheduled time and stop it at the end of the envelope
     so nodes are collected rather than accumulating.

     every Phase 5 assertion measures it, and that no audio file exists anywhere in the project.
